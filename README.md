# 🎮 Tic-Tac-Toe

A clean, responsive **Tic-Tac-Toe game** built as a single self-contained HTML file — no frameworks, no build tools, and no external dependencies.

## ✨ Features

- ❌⭕ Classic Tic-Tac-Toe gameplay
- 👥 Player vs Player mode
- 🤖 Player vs Computer mode
- 🎯 Easy and **Impossible** AI difficulty
- 🧠 Impossible mode uses the minimax algorithm
- 🏆 Automatic win and draw detection
- 💚 Winning cells are highlighted
- 📊 In-game score tracking
- 📱 Responsive design for desktop and mobile
- ♿ Accessible buttons and live game-status updates
- ⚡ Zero dependencies
- 🌐 Runs entirely in the browser

## 🚀 Getting Started

No installation is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/causcauerosadev/tictactoe.git
   ```

2. Open `index.html` in your browser.

That's it! 🎉

## 🕹️ How to Play

### Player vs Player

Two players take turns placing **X** and **O** on the 3×3 board.

### Player vs Computer

Play as **X** against the computer as **O**.

- **Easy** — the computer makes mostly random moves, with occasional smarter moves.
- **Impossible** — the computer uses minimax and will never make a losing move.

Get three of your marks in a row horizontally, vertically, or diagonally to win.

## 🌐 GitHub Pages

Because this project is a static website with no build step, it can be deployed directly with **GitHub Pages**.

Set the Pages source to the `main` branch and the repository root (`/`). GitHub Pages will serve `index.html` as the game homepage.
